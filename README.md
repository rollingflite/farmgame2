# 작은 농장 (farmgame2)

`sprite_a`에서 만든 8방향 농부를 주인공으로 한 브라우저 농사 게임이에요. 빌드 없이 돌아가요.

```sh
npm run dev     # http://localhost:4174, 같은 내부망에서는 http://192.168.0.76:4174
npm test        # 규칙·맵 테스트
```

## 조작
- WASD / 방향키: 이동
- Space / 클릭: 앞 칸에 도구 사용, 다 자란 작물 수확. Space를 누르고 있으면 계속 작업해요.
- E / 우클릭: 문(잠자기), 판매함, 씨앗 가게
- 1–9 / 마우스 휠: 도구 고르기, H: 도움말
- 터치 화면: 왼쪽 절반을 끌어서 이동, 오른쪽 버튼으로 행동

## 규칙
- 괭이로 울타리 안 밭을 갈고, 씨앗을 심고, 물을 줘요. 물 준 날 밤에만 작물이 하루 자라요.
- 순무 3일 / 당근 4일 / 양배추 6일. 씨앗은 동쪽 가게에서 사요.
- 수확물은 판매함에 넣으면 다음 날 아침 정산돼요.
- 물뿌리개(20회)는 연못에서 채워요. 괭이질은 기력 2, 물주기는 1을 써요.
- 하루는 오전 6시에 시작해요. 새벽 2시까지 안 자면 쓰러지고 기력이 60%만 회복돼요.
- 비 오는 날(20%)은 모든 밭에 물이 저절로 줘져요. 심지 않은 밭은 마르면 조금씩 원래 흙으로 돌아가요.
- 잠잘 때, 15초마다, 창을 닫을 때 브라우저 localStorage에 자동 저장돼요.

## 구성
- `assets/farmer.png`: 32×48, 8방향 × 8프레임 시트(행 순서와 서 있는 프레임은 `farmer.json`에 있어요)
- `assets/maple.png`: 메이플. Codex 이미지 생성으로 처음부터 뽑은 캐릭터예요(빨간 단발·초록 두건·앞치마 원피스·장화).
  처음 시작할 때 농부와 메이플 중에 고르고, 왼쪽 위 `캐릭터` 버튼으로 언제든 바꿀 수 있어요.
  원본 시트와 프롬프트는 `art-src/maple/`에 있어요. 동·남·남동·북동·북 5장을 받아 서쪽은 좌우 반전해요.
  새 캐릭터도 같은 형식(1774×887, 4×2칸, 8프레임) 5장을 `art-src/<이름>/`에 넣고
  `python3 tools/build_character.py art-src/<이름> <이름>`을 실행한 뒤 `src/model.js`의 `LOOKS`에 이름을 추가하면 돼요.
- `assets/<이름>-hoe.png`: 괭이질 동작(남·북·동, 서는 반전, 8프레임). Codex가 그린 `art-src/<이름>/hoe-*.png`를
  `python3 tools/build_action.py art-src/<이름> <이름> hoe <땅에 닿는 프레임>`으로 줄여요.
  크기는 걷기 시트에서 재서 캐릭터가 걸을 때와 같은 크기로 나와요. 이 시트가 없는 캐릭터는 아이콘을 휘두르는 효과로 대신해요.
  괭이와 물뿌리개는 키를 누른 순간이 아니라 도구가 땅에 닿는 순간에 밭이 바뀌어요.
- `tools/build_farmer.py`: `../sprite_a/output/farmer-8way/farmer-8way-sheet.png`(256px)를 축소해 위 시트를 만들어요.
  최근접 샘플링을 써요. 평균 방식은 눈이 뭉개지고, 팔레트 고정 방식은 모자 색이 바래서 제외했어요.
- `src/world.js`: 맵(지형·충돌·오브젝트 배치). `src/model.js`: 게임 규칙·저장 형식. 둘 다 DOM 없이 테스트돼요.
- `src/art.js`: 타일·나무·집·가게·작물·아이콘을 코드로 그려요(외부 그림 파일은 농부만 써요).
- `src/render.js`: 캔버스 렌더링, y 정렬, 날씨·밤 조명. `src/main.js`: 입력·HUD·대화창·저장.
